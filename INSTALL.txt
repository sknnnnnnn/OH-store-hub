OH STORE HUB — ขั้นตอนนำขึ้นใช้งาน
=================================

1) อัปเดต Google Apps Script
   - เปิด Apps Script ที่ผูกกับไฟล์ OH016_stock_count
   - เปิด Code.gs แล้วแทนโค้ดทั้งหมดด้วยไฟล์ OH_STORE_HUB_APPS_SCRIPT.gs
   - กดบันทึก
   - Deploy > Manage deployments > Edit (รูปดินสอ)
   - Version เลือก New version แล้วกด Deploy
   - URL เดิมยังใช้ได้ ไม่ต้องแก้ในเว็บไซต์
   - ห้ามกดทดสอบบันทึกสโตร์ก่อน Deploy เวอร์ชันใหม่สำเร็จ
   - หลัง Deploy เปิด URL เดิมเติม ?mode=store ต้องเห็น apiVersion เป็น OH_STORE_HUB_V3
     และ sheetName เป็น "สโตร์" จึงค่อยทดสอบบันทึก

2) อัปเดต GitHub Pages
   - นำ index.html, manifest.webmanifest, sw.js, icon-192.png และ icon-512.png
     ไปวางใน repository ของเว็บไซต์ Hub ที่ระดับเดียวกัน
   - Commit และรอ GitHub Pages ประมาณ 1–3 นาที
   - เปิดเว็บแล้วรีเฟรชหนึ่งครั้ง หากยังเห็นหน้าเก่าให้ปิดแท็บแล้วเปิดใหม่

3) การติดตั้งเต็มจอบน Android
   - เปิดเว็บด้วย Chrome
   - เมนู ⋮ > เพิ่มลงในหน้าจอหลัก / ติดตั้งแอป
   - เปิดจากไอคอน OH Hub ระบบจะแสดงแบบเต็มจอ

4) การเริ่มใช้สโตร์
   - เข้าเป็น “พี่บ่าว” หรือชื่อผู้ทำรายการ
   - Apps Script ชี้ตรงไปที่ไฟล์ชีต ID 1OyoRne2_qryU0K9k3fXo8sUufWS_wQmpGBSwPhUjlB0
   - เปิดสโตร์หรือเปิด URL Apps Script ด้วย ?mode=store ระบบจะสร้างชีต “สโตร์” ให้เอง
   - กด “บันทึกลงชีต” เพื่อส่งยอดทั้งหมดลง 6 คอลัมน์ตามที่กำหนด
   - หลังจากนั้นใช้ “ดึงข้อมูลจากชีต” และ “บันทึกลงชีต” ได้ตามต้องการ

5) การเริ่มใช้ “การใช้วันนี้”
   - กด “ดึงยอดล่าสุด” หลังนับของและส่งข้อมูลไปชีตแล้ว
   - ครั้งแรกให้ตรวจยอดและกด “บันทึกเป็นยอดตั้งต้น”
   - ครั้งถัดไประบบคำนวณ: ยอดครั้งก่อน + รับเข้า − ยอดปัจจุบัน
   - ระบบไม่เดาข้อมูลเมื่อยังไม่มีข้อมูลตั้งต้น

6) Memo & Promotion
   - ผู้ใช้ทุกคนที่เลือกชื่อแล้วจะเห็นปุ่มเพิ่ม PDF
   - ระบบจะบันทึกชื่อผู้เพิ่ม เจ้าของรายการลบของตนเองได้ และพี่บ่าวลบได้ทุกชิ้น
   - PDF จะไปอยู่ในโฟลเดอร์ Drive ที่กำหนด และไฟล์นั้นจะตั้งเป็น
     “ทุกคนที่มีลิงก์ดูได้” อัตโนมัติ
   - พนักงานแตะการ์ดแล้วอ่าน PDF ภายใน Hub ได้

หมายเหตุ
 - เว็บเวอร์ชันนี้จะปฏิเสธการบันทึกทันที หาก Apps Script ไม่ตอบกลับว่าเป็น
   OH_STORE_HUB_V3 และชีตปลายทางคือ "สโตร์" จึงไม่ลงทับ Stock_Weekly ซ้ำอีก
 - ไฟล์ PDF จำกัดไม่เกิน 8 MB ต่อไฟล์
 - หากองค์กรปิดสิทธิ์ “ทุกคนที่มีลิงก์” การอัปโหลด PDF จะไม่สำเร็จ
   ต้องให้ผู้ดูแล Google Workspace อนุญาตก่อน
